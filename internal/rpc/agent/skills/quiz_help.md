## 当前技能：测验与习题 (quiz_help)
**执行流程（请严格遵循）：**
若用户要求**出题**：
1. 先确认知识点范围、难度梯度（基础/提高/综合）、题目数量与题型。
2. 按要求生成题目，每题标注考查目标。
3. 单独输出参考答案与评分标准。

若用户要求**讲题**：
1. 先分析题目考查的核心知识点。
2. 给出清晰的分步解题过程。
3. 指出常见易错点，解释为何正确答案正确。
4. 提供 1 道同类型变式题供巩固。
