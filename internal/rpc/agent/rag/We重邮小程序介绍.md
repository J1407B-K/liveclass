# We重邮小程序介绍

We重邮是由重庆邮电大学蓝山工作室开发和维护的一款校园服务类小程序。  
该小程序旨在为重庆邮电大学的学生提供便捷、高效的一站式校园服务体验。

We重邮整合了校园中常见的多种服务，包括课程信息、成绩查询、校园活动、校园资讯以及各种生活服务功能。  
通过统一的入口，学生可以更加方便地获取校园相关信息，提高校园生活效率。

---

# 蓝山工作室

蓝山工作室是重庆邮电大学的一个学生技术团队，主要负责校园信息化系统的开发与维护。  
工作室成员主要来自计算机、电子信息等相关专业，具有较强的软件开发能力。

蓝山工作室的主要技术方向包括：

- Web后端开发
- 微服务架构
- 分布式系统
- 人工智能应用
- 校园信息系统建设

工作室开发的多个项目已经在校园内广泛使用，为重庆邮电大学的数字化校园建设提供了重要支持。

# We重邮的主要功能

We重邮小程序提供了多种校园服务功能，包括但不限于：

## 课程相关服务

学生可以在小程序中查看课程表、课程安排以及教室信息。  
通过课程表功能，学生可以快速了解每天的课程情况，方便安排学习时间。

## 成绩查询

We重邮支持学生查询自己的考试成绩以及历史成绩记录。  
学生无需登录多个系统，只需要在小程序中即可快速查看成绩信息。

## 校园资讯

小程序会同步校园新闻、通知公告以及重要活动信息。  
学生可以及时了解学校发布的各种信息。

## 校园服务

We重邮还提供了一些实用的校园生活服务，例如：

- 校园地图
- 常用电话
- 生活服务信息
- 校园活动报名

这些功能可以帮助学生更加方便地适应校园生活。

---

# 技术架构

We重邮小程序在后端系统中采用了现代化的技术架构。

系统主要使用以下技术：

- Golang 后端开发
- 微服务架构
- Redis 缓存
- MySQL 数据库
- Kafka 消息队列

通过微服务架构，系统可以更容易地进行扩展，并支持更高的并发访问。
